# Essax 2.0 — Complete Flutter Project

This is the complete FlutLab-ready Essax project.

## Platforms
- Android
- iOS
- Web
- Flutter/Dart source

## Essax direction
Red-to-orange gradient brand, clean Material 3 writing studio, essay library,
search, editor, word count, favorites, local persistence, and profile.

## Build
1. Open/import the project in FlutLab.
2. Run `flutter pub get`.
3. Run the Android target.
4. Once it works in FlutLab, push this project to GitHub and connect it to CodeMagic.

Do not replace the generated Android or iOS platform folders with the old Essax project.
